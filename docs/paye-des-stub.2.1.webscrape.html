Create Child Benefit entitlement test data

Supports the Individual Benefits API by creating Child Benefit entitlement test data.

Authorizations:
Application-Restricted
path Parameters
utr
required
string
Example: 2234567890

The 10 digit self assessment UTR for the individual.

taxYear
required
string^[0-9]{4}-[0-9]{2}$
Example: 2025-26

The tax year for the Child Benefit entitlement test data that is being created. Although production data will only be available for a portion of the current Self Assessment year, that policy is not enforced for the data that is created in the sandbox environment by this operation.

Create Winter Fuel Payment test data

Supports the Individual Benefits API by creating Winter Fuel Payment test data.

Unlike the other endpoints in this API, this endpoint is keyed by National Insurance number rather than Unique Taxpayer Reference. The Individual Benefits API is called with a Self Assessment Unique Taxpayer Reference.

You will therefore need to take note of both IDs when you create a test user.

Authorizations:
Application-Restricted
path Parameters
nino
required
string^[A-Z]{2}[0-9]{6}[A-Z]$
Example: SA123456A

The National Insurance number for the individual.

taxYear
required
string^[0-9]{4}-[0-9]{2}$
Example: 2025-26

The tax year for the Winter Fuel Payment test data being created.

header Parameters
Accept
required
string
Value: "application/vnd.hmrc.2.1+json"

Specifies the response format and the version of the API to be used.

Content-Type
required

Specifies the format of the request body, which must be JSON.

Authorization
required
string
Example: Bearer 59fc92c1cdf0b8ef1f138a702effdbd2

An OAuth 2.0 Bearer Token.

Request Body schema: application/json
required
firstScenario (string) or happy404Scenario (string) or unhappy500Scenario (string)

The scenario for which to create Winter Fuel Payment test data.

Responses

https://test-api.service.hmrc.gov.uk/individual-paye-test-support/{nino}/winter-fuel-payment-amount/annual-summary/{taxYear}
