Create and Amend CGT Residential Property Disposals (non-PPD)

This endpoint enables you to submit residential property disposals that are not reported via the 'Report and pay Capital Gains Tax on UK property' service (not payment for property disposal) for a given National Insurance number and tax year.

The disposal date must be within the specified tax year. The completion date must be within the specified tax year and not in the future. If the specified tax year has not ended, the completion date must be between 7th March and 5th April.

Test data

Scenario simulation using Gov-Test-Scenario headers is only available in the sandbox environment.

Header Value (Gov-Test-Scenario) Scenario
N/A - DEFAULT Simulates success response.
ACQUISITION_DATE_AFTER_DISPOSAL_DATE Simulates a scenario where acquisitionDate is later than disposalDate.
INVALID_COMPLETION_DATE Simulates a scenario where the completionDate is not within the specific tax year or in the future. If the specified tax year has not ended, the completionDate must be between 7th March and 5th April.
INVALID_DISPOSAL_DATE Simulates a scenario where the disposalDate is not within the specified tax year.
OUTSIDE_AMENDMENT_WINDOW Simulates the scenario where request cannot be completed as it is outside the amendment window.
STATEFUL Performs a stateful create or update.

This endpoint enables you to retrieve the residential property disposals subject to capital gains tax for payment for property disposal (PPD). This includes:

  • Disposals previously reported via the HMRC 'Report and Pay Capital Gains Tax on UK Property'
  • User submitted disposal overrides

Test data

Scenario simulation using Gov-Test-Scenario headers is only available in the sandbox environment.

Header Value (Gov-Test-Scenario) Scenario
N/A - DEFAULT
?source=user		 Requesting user source simulates success response with User provided disposals and overrides.
N/A - DEFAULT
?source=hmrc-held		 Requesting hmrc-held source simulates success response with HMRC held disposals.
N/A - DEFAULT
?source=latest		 Requesting latest source simulates success response with Latest disposals and overrides submitted.
LOSS
source=latest		 Requesting latest source with LOSS simulates success response with User provided disposals and overrides with losses.
NOT_FOUND Simulates the scenario where no data is found.
STATEFUL Performs a stateful retrieve.

Information and data held by HMRC is not available in the sandbox environment. Providing ‘source=hmrc-held’ will result in the expected HTTP 404 (matching resource not found) error being returned.

REQUEST_CANNOT_BE_FULFILLED Simulates the scenario where the request cannot be fulfilled for various reasons other than the ones triggering other errors.

Create and Amend Other Capital Gains and Disposals

This endpoint enables you to submit other capital gains and disposals with the exception of residential property, for a given National Insurance number and tax year.

Test data

Scenario simulation using Gov-Test-Scenario headers is only available in the sandbox environment.

Header Value (Gov-Test-Scenario) Scenario
N/A - DEFAULT Simulates success response with gains.
INVALID_DISPOSAL_DATE Simulates a scenario where disposalDate is not within the specified tax year or later than today's date.
INVALID_ACQUISITION_DATE Simulates a scenario where acquisitionDate is later than disposalDate.
OUTSIDE_AMENDMENT_WINDOW Simulates the scenario where request cannot be completed as it is outside the amendment window.
STATEFUL Performs a stateful create or update.
REQUEST_CANNOT_BE_FULFILLED Simulates the scenario where the request cannot be fulfilled for various reasons other than the ones triggering other errors.

path Parameters
nino
required
string
Example: TC663795B

National Insurance number, in the format AA999999A

taxYear
required
string
Example: 2021-22

The tax year the data applies to, for example, 2021-22. The start year and end year must not span two tax years. The minimum tax year is 2021-22. No gaps are allowed, for example, 2020-22 is not valid. (The minimum tax year in Sandbox is 2019-20.)

Request Body schema: application/json
Any of
Array of objects

An array of other Capital Gains disposals.

object

One of these fields must be provided: carriedInterestGain, attributedGains or otherGains

object

Details Capital Gains Tax losses relating to other disposals and non-standard gains. One of these fields must be provided: broughtForwardLossesUsedInCurrentYear, setAgainstInYearGains, setAgainstInYearGeneralIncome or setAgainstEarlierYear

adjustments
number decimal places <= 2 [ -99999999999.99 .. 99999999999.99 ]

The amount of included adjustments to reduce or increase the Capital Gains Tax payable. The value must be between -99999999999.99 and 99999999999.99 up to 2 decimal places.
