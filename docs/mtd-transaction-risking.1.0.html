VAT Assist (MTD) (1.0)

Download OpenAPI specification:

Overview

Use this API to get HMRC Assist feedback about potential inaccuracies in returns before they are formally submitted. You must follow a two-step process:

  1. Send draft return data.
  2. Use the relevant acknowledgement endpoint to confirm that your software has presented the HMRC Assist feedback messages to the user.

Because this process operates on draft, unfinalised data, requesting feedback carries no formal declaration. Also, the process does not block formal declaration submission via the returns endpoint of the VAT (MTD) API. Your software must allow customers to submit their VAT return, irrespective of any HMRC Assist submission feedback.

Request HMRC Assist feedback for VAT [test only]

Send VAT return data, to receive feedback from HMRC before formally submitting a VAT return.

The response will contain feedback messages in English and Welsh, highlighting potential mistakes or discrepancies in the VAT return data.

Note: Before using this endpoint, you must first call the obligations endpoint on the VAT (MTD) API to get the period key.

Test data

Scenario simulations using Gov-Test-Scenario headers are only available in the sandbox environment.

Header Value (Gov-Test-Scenario) Scenario

Default (No header value)

Simulates the scenario where there is one HMRC Assist feedback message.

MULTIPLE_FEEDBACK

Simulates the scenario where there are more than one HMRC VAT Assist feedback messages.

NO_FEEDBACK

Simulates the scenario where there is no HMRC VAT Assist feedback.

INVALID_VRN

Simulates the scenario where the VRN has not passed validation.

INVALID_PERIODKEY

Simulates the scenario where the periodKey has not passed validation.

INVALID_REQUEST

Submission has not passed validation. Invalid values.

TAX_PERIOD_NOT_ENDED

Simulates the scenario where the accounting period has not ended.

INSOLVENT_TRADER

Simulates the scenario where the client is an insolvent trader.

Request Body schema: application/json
required
periodKey
required
string = 4 characters ^[#0-9A-Z]{4}$

The ID code for the period that this obligation belongs to. This should be obtained from the obligations endpoint of the VAT (MTD) API. The format is a string of four alphanumeric characters. Occasionally the format includes the # symbol.

vatDueSales
required
number decimal places <= 2 [ -9999999999999.99 .. 9999999999999.99 ]

VAT due on sales and other outputs. This corresponds to box 1 on the VAT Return form.

vatDueAcquisitions
required
number decimal places <= 2 [ -9999999999999.99 .. 9999999999999.99 ]

VAT due in the period on acquisitions of goods made in Northern Ireland from EU Member States. This corresponds to box 2 on the VAT Return form.

totalVatDue
required
number decimal places <= 2 [ -9999999999999.99 .. 9999999999999.99 ]

Total VAT due (the sum of vatDueSales and vatDueAcquisitions). This corresponds to box 3 on the VAT Return form.

vatReclaimedCurrPeriod
required
number decimal places <= 2 [ -9999999999999.99 .. 9999999999999.99 ]

VAT reclaimed in the period on purchases and other inputs (including acquisitions in Northern Ireland from EU member states). This corresponds to box 4 on the VAT Return form.

netVatDue
required
number decimal places <= 2 [ 0 .. 99999999999.99 ]

The absolute difference between the totalVatDue and vatReclaimedCurrPeriod values. This should therefore be a positive number, calculated by subtracting the smallest value from the largest. HMRC will automatically determine whether the number represents net VAT that is due or net VAT that can be reclaimed.

This corresponds to box 5 on the VAT Return form.

totalValueSalesExVAT
required
number [ -9999999999999 .. 9999999999999 ]

Total value of sales and all other outputs excluding any VAT. This corresponds to box 6 on the VAT Return form. The value must be in whole pounds (no pence).

totalValuePurchasesExVAT
required
number [ -9999999999999 .. 9999999999999 ]

Total value of purchases and all other inputs excluding any VAT (including exempt purchases). This corresponds to box 7 on the VAT Return form. The value must be in whole pounds (no pence).

totalValueGoodsSuppliedExVAT
required
number [ -9999999999999 .. 9999999999999 ]

Total value of dispatches of goods and related costs (excluding VAT) from Northern Ireland to EU Member States. This corresponds to box 8 on the VAT Return form. The value must be in whole pounds (no pence).

totalAcquisitionsExVAT
required
number [ -9999999999999 .. 9999999999999 ]

Total value of acquisitions of goods and related costs (excluding VAT) made in Northern Ireland from EU Member States. This corresponds to box 9 on the VAT Return form. The value must be in whole pounds (no pence).
