CTC Guarantee Balance (2.0)

Download OpenAPI specification:

Overview

Use the CTC Guarantee Balance API to provide traders with up-to-date information about how much of their guarantee funds they have left to use when organising transit movements. For a detailed overview of v2.0 of the API, see CTC Guarantee Balance API phase 5 service guide.

Get a balance

Get the balance associated with a guarantee reference number (GRN).

Authorizations:
User-Restricted

required
