Send a push notification to the HMRC mobile app

This endpoint allows a calling system to send a push notification to the HMRC app and supply the content

Authorizations:
User-Restricted
Request Body schema: application/json
required
identifier
required
string

The value assigned to the users account to determine if they are registered or not

identifierType
required
string

The type of identifier e.g NINO, SAUTR, CREDID or MTDIT

notificationTitle
required
string

The title of the notification, must be 60 characters or less

notificationBody
required
string

The body of the notification, must be 160 characters or less

appChannelId
required
string

The channel Id of the notification (Used by android)

appPath
required
string

The location the user should be taken to in the app when the notification is clicked

Responses

Sandbox

https://test-api.service.hmrc.gov.uk/mobile/push-notifications-orchestration/send/pega

Production

https://api.service.hmrc.gov.uk/mobile/push-notifications-orchestration/send/pega
