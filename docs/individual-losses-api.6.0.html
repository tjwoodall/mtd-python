Brought Forward Losses

Resources related to a customer’s financial data for their brought forward losses.

Create a Brought Forward Loss

This endpoint enables you to create a new brought forward loss which can be submitted against self-employment, self-employment class 4, UK Furnished Holiday Let (FHL) property, UK other (Non-FHL) property, foreign property FHL in the European Economic Area (EEA) and foreign property for the tax year prior to joining MTD. A National Insurance number and tax year must be provided.

This endpoint supports tax years up to, and including, 2025-26. For tax years 2026–27 onwards, a new version is in development.

Note: Brought forward losses for the following 2 income sources will not be supported from tax year 2025-26 onwards:
  • uk-property-fhl
  • foreign-property-fhl-eea

Delete a Brought Forward Loss

This endpoint allows a developer to delete an existing brought forward loss. A National Insurance number, tax year and Loss ID must be provided. The user should be aware that where a loss has been used as part of a successful final declaration activity, deletion will be blocked and an error code will be returned. In such a case, the user can amend the loss amount to zero.

This endpoint supports tax years up to, and including, 2025-26. For tax years 2026–27 onwards, a new version is in development.

Loss Claims

Resources related to a customer’s financial data for their loss claims.

Create a Loss Claim

This endpoint enables you to create a loss claim against an income source for a specific tax year. Claims cannot be made until after the end of the accounting period. A National Insurance number must be provided.

This endpoint supports tax years up to, and including, 2025-26. For tax years 2026–27 onwards, a new version is in development.

Note: carry-sideways-fhl type of loss claims for income sources uk-property-fhl and foreign-property-fhl-eea will not be supported from tax year 2025-26 onwards.

Amend a Loss Claim Type

This endpoint enables you to change the type of claim for an existing loss claim type. A National Insurance Number, tax year and Claim ID must be provided.

This endpoint supports tax years up to, and including, 2025-26. For tax years 2026–27 onwards, a new version is in development.

Note: carry-sideways-fhl type of loss claims for income sources uk-property-fhl and foreign-property-fhl-eea will not be supported from tax year 2025-26 onwards.

Scenario simulation using Gov-Test-Scenario headers is only available in the sandbox environment.

N/A - DEFAULT Simulates success response.

FP_SIDEWAYS Simulates a Foreign Property carried sideways scenario.
