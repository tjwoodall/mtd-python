Individuals Savings Income (MTD) (2.0)

Download OpenAPI specification:

Send fraud prevention data

HMRC monitors transactions to help protect your customers' confidential data from criminals and fraudsters.

! Warning You are required by law to submit header data for this API. This includes all associated APIs and endpoints.

Check the data you need to send. You can also use the Test API during initial development and as part of your quality assurance checks.

Mapping APIs to Self Assessment tax return forms

Some parameters in this API map to box numbers in one or more Self Assessment tax return forms. To learn more and to download this mapping information as a CSV file, go to income-tax-mtd-changelog/mapping on GitHub.

Changelog

You can find the changelog in the income-tax-mtd-changelog on GitHub.

Create and Amend a UK Savings Account Annual Summary

This endpoint enables you to create and amend a UK savings account annual summary for a tax year. This enables supplying savings interest for a previously added savings account. A National Insurance number, Savings Account ID, and tax year must be provided. To delete a previously submitted value, submit a value of 0.00.

Test data

Scenario simulation using Gov-Test-Scenario headers is only available in the sandbox environment.

Header Value (Gov-Test-Scenario) Scenario
N/A - DEFAULT Simulates success response.
NOT_FOUND Simulates the scenario where no data is found.
STATEFUL Performs a stateful create or update.

Use the savingsAccountId of a savings account created with Add a UK Savings Account, otherwise a MATCHING_RESOURCE_NOT_FOUND error will be returned.
REQUEST_CANNOT_BE_FULFILLED Simulates the scenario where the request cannot be fulfilled for various reasons other than the ones triggering other errors.
OUTSIDE_AMENDMENT_WINDOW Simulates the scenario where request cannot be completed as it is outside the amendment window.

User-Restricted

required

Request Body schema: application/json
taxedUkInterest
number decimal places <= 2 [ 0 .. 99999999999.99 ]

Total net taxed interest for the specified savings account. The value must be between 0 and 99999999999.99 up to 2 decimal places. Note: If taxedUkInterest is not provided, then any existing values will be removed.

untaxedUkInterest
number decimal places <= 2 [ 0 .. 99999999999.99 ]

Total untaxed interest for the specified savings account. The value must be between 0 and 99999999999.99 up to 2 decimal places. Note: If untaxedUkInterest is not provided, then any existing values will be removed.
