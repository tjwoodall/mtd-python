marriage-allowance-test-support

Create Marriage Allowance eligibility test data

Lets you create Marriage Allowance eligibility test data.

Supports the Check Marriage Allowance eligibility resource method on the Marriage Allowance API.

Authorizations:
Application-Restricted
path Parameters
nino
required
string
Example: AA000003D

Partner’s (potential recipient’s) National Insurance number. This must match the National Insurance number of an individual created using the Create Test User API.

taxYear
required
string^[0-9]{4}-[0-9]{2}$
Example: 2016-17

The tax year for which the Marriage Allowance eligibility is being created.

Request Body schema: application/json
required
eligible
required
boolean

Whether the taxpayer's partner is eligible to become a recipient of Marriage Allowance

Responses

https://api.service.hmrc.gov.uk/marriage-allowance-test-support/nino/{nino}/eligibility/{taxYear}
https://test-api.service.hmrc.gov.uk/marriage-allowance-test-support/nino/{nino}/eligibility/{taxYear}

Create Marriage Allowance status test data

Lets you create Marriage Allowance status test data.

Supports the Get Marriage Allowance status resource method on the Marriage Allowance API.

Authorizations:
Application-Restricted
path Parameters
utr
required
string
Example: 2234567890

The 10 digit self assessment UTR for the individual.

taxYear
required
string^[0-9]{4}-[0-9]{2}$
Example: 2016-17

The tax year for which the Marriage Allowance status is being created.

Request Body schema: application/json
required
required
Status (string) or Status1 (string) or Status2 (string)

The role of the taxpayer as recipient or transferor

deceased
