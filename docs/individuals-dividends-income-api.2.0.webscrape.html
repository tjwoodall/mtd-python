Dividends Income

These endpoints allow a user to create, amend, retrieve and delete Dividends

Delete Dividends Income

This endpoint enables you to delete dividends income: foreign dividend, dividend income received whilst abroad, stock dividend, redeemable shares, bonus issues of securities and close company loans written off. A National Insurance number and tax year must be provided.

Test data

Scenario simulation using Gov-Test-Scenario headers is only available in the sandbox environment.

Header Value (Gov-Test-Scenario) Scenario
N/A - DEFAULT Simulates success response.
NOT_FOUND Simulates the scenario where no data is found.
REQUEST_CANNOT_BE_FULFILLED Simulates the scenario where the request could not be processed.
OUTSIDE_AMENDMENT_WINDOW Simulates the scenario where request cannot be completed as it is outside the amendment window.
STATEFUL Performs a stateful delete.
Authorizations:
User-Restricted
path Parameters
nino
required
string
Example: TC663795B

National Insurance number, in the format AA999999A

taxYear
required
string
Example: 2021-22

The tax year the data applies to, for example, 2021-22. The start year and end year must not span two tax years. The minimum tax year is 2021-22. No gaps are allowed, for example, 2020-22 is not valid. (The minimum tax year in Sandbox is 2019-20.)

Request Body schema: application/json
companyDirector
required
boolean

Indicates whether a taxable entity is a director or not

closeCompany
boolean

Indicates whether the company is a close company. This is required where companyDirector property is true.

directorshipCeasedDate
string <date>

Date when the directorship ceased. This will cease the rollover across tax years for custom employments that were created for Additional Dividends and Directorship. Must conform to the format YYYY-MM-DD

companyName
string^.{0,160}$

The name by which the company is registered with Companies House. This is required where closeCompany is true.

companyNumber
string^(?:\d{8}|[A-Za-z]{2}\d{6})$

The number by which the company is registered with Companies House. This is required where closeCompany is true.

shareholding
number decimal places <= 2 [ 0 .. 100 ]

The percentage shareholding of the company. This is required where closeCompany is true. Where there is no shareholding, a zero can be submitted.

The value must be between 0 and 100 up to 2 decimal places.

dividendReceived
number decimal places <= 2 [ 0 .. 99999999999.99 ]

The amount of dividends received from the company. This is required where closeCompany is true. Where no dividends are received, a zero can be submitted.

The value must be between 0 and 99999999999.99 up to 2 decimal places.
