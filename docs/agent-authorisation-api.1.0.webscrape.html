Create a new authorisation

Create a new authorisation request. The request will expire after 21 days.

Authorizations:
User-Restricted
path Parameters
arn
required
string
Example: AARN9999999

The Making Tax Digital (MTD) platform Agent Reference Number. For format and validation of Agent Reference Number See here

header Parameters
Accept
required
string
Value: "application/vnd.hmrc.1.0+json"

Specifies the response format and the version of the API to be used.

Content-Type
required
string
Value: "application/json"

The media type of the request body.

Request Body schema: application/json
required
One of
service
required
string
Value: "MTD-IT"

MTD IT service

clientType
required
string
Value: "personal"

An individual or sole trader

clientIdType
required
string
Value: "ni"
clientId
required
string (National Insurance Number) ^[ABCEGHJKLMNOPRSTWXYZ][ABCEGHJKLMNPRSTWXYZ]?...
knownFact
required
string (Postcode) ^[A-Z]{1,2}[0-9][0-9A-Z]?\s?[0-9][A-Z]{2}$|BF...
agentType
string or null (Agent type)
Enum: "main" "supporting"

Only MTD-IT supports this field. Defaults to "main" if omitted.
