National Insurance Test Support (1.0)

Download OpenAPI specification:

Create National Insurance summary test data

Lets you create National Insurance contributions test data

Authorizations:
Application-Restricted
path Parameters
utr
required
string
Example: 2234567890

The 10 digit self-assessment UTR for the individual.

taxYear
required
string^[0-9]{4}-[0-9]{2}$
Example: 2016-17

The tax year for the National Insurance contribution being created.

header Parameters
Accept
required
string
Value: "application/vnd.hmrc.1.0+json"

Specifies the response format and the version of the API to be used.

Content-Type
required
string
Value: "application/json"

Specifies the format of the request body, which must be JSON.

Authorization
required
string
Example: Bearer 59fc92c1cdf0b8ef1f138a702effdbd2

An OAuth 2.0 Bearer Token.

Request Body schema: application/json
required
firstScenario (string) or secondScenario (string)

The scenario to create test data for National Insurance

Responses

https://test-api.service.hmrc.gov.uk/national-insurance-test-support/sa/{utr}/annual-summary/{taxYear}
