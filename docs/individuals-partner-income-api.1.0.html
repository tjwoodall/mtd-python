The following endpoints are stateful in the Sandbox:

  • List All Partner Income Submissions

Send fraud prevention data

HMRC monitors transactions to help protect your customers' confidential data from criminals and fraudsters.

! Warning You are required by law to submit header data for this API. This includes all associated APIs and endpoints.

Check the data you need to send. You can also use the Test API during initial development and as part of your quality assurance checks.

Mapping APIs to Self Assessment tax return forms

Some parameters in this API map to box numbers in one or more Self Assessment tax return forms. To learn more and to download this mapping information as a CSV file, go to income-tax-mtd-changelog/mapping on GitHub.

List All Partner Income Submissions

This endpoint enables you to retrieve a list of all partner income submissions. A National Insurance number and tax year must be provided.

Test data

Scenario simulation using Gov-Test-Scenario headers is only available in the sandbox environment.

Header Value (Gov-Test-Scenario) Scenario
N/A - DEFAULT Simulates success response.
NOT_FOUND Simulates the scenario where no data is found.
STATEFUL Performs a stateful list.
Authorizations:
User-Restricted
path Parameters
nino
required
string
Example: TC663795B

National Insurance number, in the format AA999999A

taxYear
required
string
Example: 2026-27

The tax year to which the data applies. The start year and end year must not span two tax years. The minimum tax year is 2026-27. No gaps are allowed, for example, 2026-28 is not valid.

header Parameters
Accept
required
string
Value: "application/vnd.hmrc.1.0+json"

Specifies the response format and the version of the API to be used.

Authorization
required
string
Example: Bearer bb7fed3fe10dd235a2ccda3d50fb

An OAuth 2.0 Bearer Token with the read:self-assessment scope.

Gov-Test-Scenario
string

Only in sandbox environment. See Test Data table for all header values.

Create or Amend Partner Income

This endpoint enables you to create or amend partner income. A National Insurance number and tax year must be provided.

Note: The partnership UTR in the request body is used to identify the submission for both creation and amendment.

Test data

Scenario simulation using Gov-Test-Scenario headers is only available in the sandbox environment.

Header Value (Gov-Test-Scenario) Scenario
N/A - DEFAULT Simulates success response.
OUTSIDE_AMENDMENT_WINDOW Simulates the scenario where request cannot be completed as it is outside the amendment window.
STATEFUL Performs a stateful create or update.
Authorizations:
User-Restricted
path Parameters
nino
required
string
Example: TC663795B

National Insurance number, in the format AA999999A

taxYear
required
string
Example: 2026-27

The tax year to which the data applies. The start year and end year must not span two tax years. The minimum tax year is 2026-27. No gaps are allowed, for example, 2026-28 is not valid.

header Parameters
Accept
required
string
Value: "application/vnd.hmrc.1.0+json"

Specifies the response format and the version of the API to be used.

Content-Type
required
string
Value: "application/json"

Specifies the format of the request body, which must be JSON.

Authorization
required
string
Example: Bearer bb7fed3fe10dd235a2ccda3d50fb

An OAuth 2.0 Bearer Token with the write:self-assessment scope.

Gov-Test-Scenario
string

Only in sandbox environment. See Test Data table for all header values.

Request Body schema: application/json
partnershipUtr
required
string^[0-9]{10}$

A Unique Taxpayer Reference (UTR) for the partnership. If you are a partner in a foreign partnership, you will not have a partnership reference, so submit your personal UTR.

partnershipName
required
string^.{1,105}$

The name of the partnership. Must not be empty or contain only whitespace.

startDate
string <date>

The date the individual joined the partnership during the tax year.

Must conform to the format YYYY-MM-DD

endDate
string <date>

The date the individual left the partnership during the tax year.

Must conform to the format YYYY-MM-DD

cashBasis
boolean

Indicates whether the partnership used cash basis (money actually received and paid out) to calculate its trading and professional income and expenses.

Array of objects non-empty

An array containing details of the partnership's trades.

object

Object containing details of Class 2 and Class 4 National Insurance contributions (NICs).

object

Object containing details of the individual's share of the partnership's untaxed savings income and related adjustments.

object

Object containing details of the individual's share of the partnership's UK property income and related adjustments.

object

Object containing details of the individual's share of the partnership's other untaxed UK income and related adjustments.

object

Object containing details of the individual's share of the partnership's income from offshore funds and related adjustments.

object

Object containing details of the individual's share of the partnership's other untaxed foreign income and related adjustments.

object

Object containing details of the individual's share of the partnership's total untaxed income, excluding savings income.

object

Object containing details of the individual's share of the partnership's dividend income and taxed income.

object

Object containing details of the individual's share of the partnership's total taxed and untaxed income.

object

Object containing details of the individual's share of the partnership's tax paid and deductions.

Production
