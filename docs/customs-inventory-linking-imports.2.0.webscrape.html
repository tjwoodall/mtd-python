CSPs requesting to present their goods to Customs.

X-Badge-Identifier
string
Example: ABC123

Represents the end-user who is interacting with the subscribed application. Must be 6 to 12 characters, consisting of any combination of numeric digits and/or upper-case letters.

Inventory Linking Imports Validate Movement Response

This validate movement response message is provided by the CSP as a result of a previous validate movement request. It represents the (positive/negative) outcome of matching a declaration Id (MRN) against the provided Inventory Consignment Reference (ICR)

Authorizations:
User-Restricted
header Parameters
Accept
required
string
Example: application/vnd.hmrc.2.0+xml

Specifies the version of the API that you want to call. See versioning.

Content-Type
required
string
Example: application/xml; charset=UTF-8

Specifies the format of the request body. Must be "application/xml; charset=UTF-8" or the request will be rejected with HTTP status code 415.

X-Badge-Identifier
string
Example: ABC123

Represents the end-user who is interacting with the subscribed application. Must be 6 to 12 characters, consisting of any combination of numeric digits and/or upper-case letters.

X-Submitter-Identifier
string
Example: GB123456789000

The EORI associated with the originating owner of the declaration. Must have a maximum length of 17 characters, consisting of any combination of numeric digits and/or letters.

X-Correlation-ID
required
string
Example: ABC123

Alpha-numeric, maximum length is 36. Specifies the correlation id sent in the movement validation request. Returning the request correlation id in the movement validation response permits backend reconciliation of request and response.
